# Event Edition Template

Use this folder as the starting point for future dated Amsterdam event editions.

- Copy `index.html` into `events/{event-slug}/index.html`.
- Copy `events.csv` into `data/{event-slug}-events.csv`.
- Replace every bracketed placeholder before publication.
- Keep `data-page="event"` and `data-edition="event"` so the shared renderer, filters, saved state, and event tokens continue to work.
- Verify every public item against a primary organiser, venue, or ticketing page before linking it from the guide.
